## Summary
Fedora 34: pip install evdev fails without python3-devel. Also: setup.py installs service file to wrong path on Fedora (not found by systemd). Multiple reporters. Community workaround: install python3-devel, then pip3 install evdev. Upstream python-evdev also has no Fedora maintainer.
