## Summary
Fedora: pip install failed because python3-devel (C headers) not installed, blocking evdev compilation. Also: setup.py installs to site-packages path not found by systemd service. Multiple reporters. Workaround: install python3-devel first, or use python3-evdev RPM package. Root cause: no official RPM package.
