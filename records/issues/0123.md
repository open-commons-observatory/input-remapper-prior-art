## Summary
Two identical joysticks (Thrustmaster T.16000M) share the same preset files. User confused that selecting device 2 shows device 1's mappings. Maintainer explained design: presets shared by model, different mappings via separate preset names. Workaround: use Copy to create a separate preset for each.
