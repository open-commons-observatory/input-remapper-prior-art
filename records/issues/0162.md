## Summary
h(k(BTN_MOUSE)) fires clicks too fast; environment batches them so only one click is perceived. Workaround: h(k(BTN_MOUSE).w(500)) adds a delay. Environment coalesces rapid mouse button events. Docs gap: add w() delay note to autofire examples.
