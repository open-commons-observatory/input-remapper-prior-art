## Summary
~/.Xmodmap interferes with key-mapper on Wayland in KDE Plasma: key-mapper uses xmodmap -pke to build the key name list, which is wrong when Xmodmap has been applied. On Wayland the Xmodmap file has no effect but xmodmap -pke still shows its values. Need to detect Wayland+KDE and use a different key lookup method.
