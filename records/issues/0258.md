## Summary
Alphanumeric keys stopped working without KEY_ prefix after migrating config to new install. Root: xmodmap.json was empty (copied from previous system where it may have been populated differently). input-remapper-gtk populates xmodmap.json on startup; service alone cannot. Fix: run the GTK app to regenerate xmodmap.json.
