Could not open uinput device in write mode. Multiple reporters on Arch. Workaround: install xf86-input-evdev to ensure uinput module loads; also modprobe uinput. Maintainer noted the uinput kernel module must be loaded; reboot sometimes sufficient. PR potential: add uinput modprobe step to docs.
