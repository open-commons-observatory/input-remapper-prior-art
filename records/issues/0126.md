## Summary
ctrl+hjkl as arrow keys fails because ctrl modifier state is passed through to injected keys (ctrl+left = word-skip). Solution: also disable ctrl_l in the mapping or map it to ctrl_l with combination disabled. X11/DE interprets injected key + held ctrl as ctrl+key.
