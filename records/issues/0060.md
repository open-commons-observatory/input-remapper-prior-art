## Summary
Razer Basilisk V2 Hypershift button not detected in key-mapper. Root cause: Hypershift is a firmware-level feature; the button doesn't send an evdev event to the OS. Cannot be mapped. Resolved by switching to a different firmware profile that sends standard events.
