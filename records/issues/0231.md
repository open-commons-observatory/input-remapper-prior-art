## Summary
Python 3.10 upgrade breaks key-mapper: package installed into python3.8 path not in python3.10 sys.path. Multiple reporters. Root: python version mismatch between pip/setup.py and system default. Fix: rebuild with python3.10 explicitly. Arch: yay -Scc clears AUR cache needed for clean rebuild.
