## Summary
Sway on Arch: autoloading on startup not working. Root: Sway affects environment variables that some systemd units depend on for X/Wayland detection; key-mapper-service starts before Sway but the .desktop autoload runs after Sway login. Workaround: run key-mapper-control --command autoload from ~/.profile or Sway autostart. Docs gap: document non-systemd-autostart environments.
