## Summary
Wayland: modifier key not released after combination macro (Control_L + combo). Root: modifier injected via forwarded device can't be released by mapped device. Fix in key-mapper-devices branch: global persistent uinputs so modifier release happens on same device. Released in v1.4.0 architecture. key_up() macro also helps.
