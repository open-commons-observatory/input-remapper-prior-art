## Summary
Logitech MX Anywhere 2 Bluetooth: autoload doesn't work after reboot on Ubuntu. Multiple reporters. Root: udev rule fires with empty DEVNAME for Bluetooth devices; service doesn't find device at the provided path. Workaround: delayed autostart via .desktop sleep. Maintainer noted TODOs: autoload without DEVNAME, retry device path lookup.
